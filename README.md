# 🌱 AgroVision

Sistema simples de reconhecimento de imagens para classificar folhas de tomateiro como **Saudável** ou **Doente**, com exportação dos resultados em CSV/JSON.

## Tecnologias utilizadas

- Python
- Streamlit
- OpenCV
- Scikit-learn

## Como executar

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Funcionalidades

- Upload de uma ou mais imagens de folhas
- Classificação automática (Saudável / Doente) com percentual de confiança
- Exportação dos resultados em **CSV** e **JSON**
